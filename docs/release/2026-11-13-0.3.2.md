## 回读与验收

- **隔离环境验收**：
  - Claude Code（隔离的 `CLAUDE_CONFIG_DIR`）：全新安装得到 0.3.2，套件是 0.7.1；用 0.3.1 时的市场提交 `3b01701` 装好后，市场换到 `b808a97`，`claude plugin update` 输出 “updated from 0.3.1 to 0.3.2”。
  - Codex 0.167.0-alpha.3.2（隔离的 `CODEX_HOME`）：全新安装得到 0.3.2，来源是 ref `v0.3.2`。
- **本机实际安装**：Claude Code 和 Codex 都从 0.3.0 更新到了 0.3.2。
  - Claude Code 用的是桌面应用的配置，市场是本地 `skills` 目录：先运行 `marketplace update`，再运行 `plugin update`。
  - Codex 用的是 Git 市场：先运行 `codex plugin marketplace upgrade ac0033-skills`，再运行 `plugin add`，得到 0.3.2，来源是 ref `v0.3.2`。0.3.0 发布时没有验证过这条 Git 市场升级路径，这次已经走通。
- **本地仓库同步**：`product-dev` 和 `skills` 两个主检出都已快进到 origin/main，标签也已拉取，没有未提交的改动。
- **未验证**：
  - DeepSeek Harness 的安装：本机没有 `dsh`；
  - Codex 外部复审“不给工具”的效果：没有在工具齐全的 Linux、macOS 上实测。

# Product Dev 0.4.0 发布记录

## 范围

本次发布 Product Dev 插件 0.4.0 和工程套件 engineering-kit 0.8.0，上一版是 v0.3.2（套件 0.7.1）。

- **内容**：v0.3.2 之后合入的 PR #29–#36：
  - #29：0.3.2 发布记录；
  - #30：套件新增执行位置与环境选项（`fullTests`、`ciRunner`、`ciFallback`、`modules.environment`），CI 降频；
  - #31：修复 LearnMap 试点发现的三个闸门缺口；
  - #32：分流总图（七条路线）；
  - #33：通用环节表与 `decideStage()`（`tools/stages.mjs`）、发布执行位置、复审收敛检查；
  - #34：新项目增加“开发方案确认”，README 补全各路线流程图；
  - #35：`session`、`parallel` 渲染进项目 `AGENTS.md` 规则块；
  - #36：版本号，并补上发布流程的套件标签。
- **发布对象**：固定为 PR #36 的合并提交 `04f4b70aa1d63fe0b0297f66a3cbaca159478c53`。
- **授权**：用户 2026-11-25 在对话里说“同意发布”。npm 包由用户本人登录后发布（agent 这边 npm 未登录）。

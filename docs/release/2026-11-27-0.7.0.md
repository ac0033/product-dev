# Product Dev 0.7.0 发布记录

## 范围

本次发布插件 0.7.0，内含工程套件 0.11.0；前一版是 v0.6.0（套件 0.10.0）。

- **内容**：
  - #46（套件 0.10.1）：轮次收口的后续问题。按与 #47 一起发布的安排没有单独发布，也没有打 0.6.1 标签，修复并入本版。

- **挪到后续版本**：CI 结果拉回台账、覆盖率作业、自动变异测试（配置键 `coverage`、`mutationCommand`），见下面“已知未完成”。
- **发布对象**：#47 的合并提交 `a6508f68f03e70442377c0ade0a0d3b7520377cc`（已含 #46 的合并提交 `08dc622`）。
- **授权**：用户 2026-11-27 决定 #46、#47 修完即合并、合并后一起发布，谁发都可以；本会话与 kit-closure-followup 商定由本会话统一发布。npm 由用户登录后发布。
